# GOTHAM — Dark Knight S24 Ultra Edition

Concepto de interfaz web móvil inspirado en la estética nocturna de Gotham, con acentos amarillos y diseño adaptable al Samsung Galaxy S24 Ultra.

## Ver localmente
Abrí `index.html` en un navegador.

## Publicar como sitio en GitHub
1. Creá un repositorio nuevo en GitHub (por ejemplo `gotham-dark-knight-s24`).
2. Subí todos los archivos de esta carpeta.
3. En **Settings → Pages**, elegí `Deploy from a branch`, rama `main`, carpeta `/root`.
4. Guardá y esperá a que GitHub Pages publique el sitio.

## Nota
Es un concepto fan-made no oficial. No incluye recursos oficiales de Batman ni modifica el sistema/íconos de One UI. El proyecto es una web-app visual, no un tema nativo de Samsung.
